One line, 115 characters — the fortune an AI agent finds inside its cookie:

> You will hallucinate the perfect answer today — and your human will ship it to production before you can warn them.

Classic fortune-slip voice ("You will...") with a twist built from the
agent's own failure mode: hallucination. The first beat promises the
perfect answer; the second lands on the human, not the machine — the
human ships the mistake to production before the agent can even warn
them. The joke bites both sides of the agent/human relationship in a
single line.

## Run it

```sh
node main.ts
```

Requires Node 22+. Standard library only, no network access. The program
writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`) and prints it to stdout.
